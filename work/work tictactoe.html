Tic Tac Toe GUI Application

Experience the timeless fun of Tic-Tac-Toe with this interactive GUI application! Play in two exciting modes: challenge a smart AI that strategically blocks losing moves and finds winning opportunities, or go head-to-head with a friend in classic two-player mode.

"A strategic journey through Tic-Tac-Toe, featuring both classic 1v1 gameplay and a smart AI that anticipates moves and counters effectively."

Project Overview

Operation Modes

File Input Mode

  • Load predefined patterns from files
  • Support for various file formats
  • Import classic Game of Life configurations

Random Configuration Mode

  • Customize grid dimensions for your simulation
  • Generate random initial states
  • Set iteration count for controlled simulation
